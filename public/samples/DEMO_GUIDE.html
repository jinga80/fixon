0준비

시연을 시작하기 전, ERP를 새 데이터로 초기화하고 역할 전환 위치를 확인합니다.

실행 단계

  1. ERP 열기 →
  2. 좌측 사이드바 하단 "🔄 데이터 초기화" 클릭 (선택사항)
  3. 헤더 우측의 역할 전환 드롭다운 위치 확인 — 여기서 4개 역할을 전환합니다.
  4. 🔔 알림 아이콘 위치 확인 — 역할 간 메시지가 여기로 들어옵니다.

💡 팁

이 가이드 페이지를 한쪽 모니터/탭에 띄워두고, ERP를 다른 탭에 띄운 채 단계를 따라가면 가장 매끄럽습니다.

2치과 — 환자 스캔 + 신규 주문

치과 역할 환자 구강을 스캔하고 Point Shower에 스플린트 제작을 의뢰합니다.

① 역할 전환

헤더 우측 드롭다운에서 "치과"를 선택합니다. 사이드바가 치과 메뉴(대시보드/신규 주문/주문 목록/환자 관리/결제)로 바뀝니다.

② 신규 주문 작성

좌측 메뉴에서 "➕ 신규 주문"을 클릭합니다.

입력 예시

환자박OO (45세, 남, TMJ 통증 완화)
스캔 방식구강스캐너 직접 스캔 (또는 치아본 → 데스크탑 스캔)
스캐너 모델Medit i700
대상 부위하악 (또는 상악/상하악)
스캔 파일"📂 샘플 사용" 버튼 클릭 — 자동으로 samples/scan_intraoral_lower.stl 로드
기공소스마일덴탈랩 (평균 24시간)

"주문 등록 → 디자인 의뢰" 버튼 클릭. 자동으로 received → design_queued로 진행하고 기공소에 알림이 발송됩니다.

✓ 확인 포인트

  • 주문 목록에 새 주문(ORD-2026-XXXX)이 추가됨
  • 상태: 디자인 대기
  • 스캔 chip(📷 하악)이 행에 표시됨

3기공소 — 스캔 검토 + 디자인 작업

기공소 역할 도착한 스캔을 검토하고 Point Shower 디자인 SW로 스플린트를 설계합니다.

① 역할 전환 → 기공소

드롭다운에서 "기공소" 선택. 알림 🔔에 새 의뢰가 들어와 있습니다.

② 작업 큐 확인

사이드바에서 "📥 작업 큐" 클릭. 칸반 형태로 3개 컬럼이 보입니다:

  • 📷 스캔 검토 / 디자인 대기
  • ✏️ 디자인 중
  • ⚠️ 재스캔 대기

③ 스캔 검토

방금 들어온 카드를 클릭 → 모달에서 스캔 데이터 섹션을 확인합니다 (방식, 스캐너, 부위, 파일명).

두 가지 액션

  1. 📷 스캔 검토 OK · 디자인 시작 — 정상 진행 (designing 상태로)
  2. ⚠️ 재스캔 요청 — 사유 입력 후 치과로 반려 (시나리오 4 참고)

④ 디자인 완료 처리

실제 시연에서는 별도 SW로 작업하지만, ERP에서는 "디자인 완료" 클릭 시 자동으로 그래피 생산 큐로 인계됩니다 (design_done → print_queued).

4(선택) 재스캔 요청 시나리오

스캔 품질이 부족할 때 기공소 → 치과로 재스캔을 요청하는 흐름입니다. 시연에서 빼도 되지만, 실제 운영에서는 자주 발생합니다.

① 기공소: 재스캔 요청

주문 모달에서 "⚠️ 재스캔 요청" 클릭 → 사유 입력 (예: "후방 어금니 데이터 누락").

② 치과: 재스캔 알림 수신

역할을 치과로 전환. 대시보드 상단에 "⚠️ 재스캔 요청 N건" 빨간 배너가 보입니다.

③ 재업로드

배너의 "재업로드" 클릭 → 새 스캔 파일 업로드 모달. samples/scan_intraoral_lower_v2.stl 사용.

제출 시 자동으로 기공소 큐로 다시 들어가며, scanData.rescanCount가 증가합니다.

✓ 확인 포인트

  • 주문 모달에 "재스캔 N회" 뱃지 표시
  • 타임라인에 재스캔 요청/재업로드 이벤트 기록

5그래피 — 인쇄 → 조립 → QC → 배송

그래피 역할 디자인 완료된 파일을 받아 실제 제품으로 만듭니다.

① 역할 전환 → 그래피

② 생산 큐 → 인쇄 시작

사이드바 "🖨️ 생산 큐" 클릭 → 카드 클릭 → "인쇄 시작" 클릭.

  • 가용 프린터(PRN-01~03 중)가 자동 배정됩니다.
  • 대시보드의 프린터 가동 현황이 "가동 중"으로 변경됩니다.

③ 인쇄 완료 → 조립

다시 모달을 열어 "인쇄 완료 → 조립" 클릭.

④ 조립 페이지

사이드바 "🔧 조립"로 이동. 체크리스트:

  • ✓ 스플린트 인쇄물 분리
  • ✓ 분사 노즐 4개 삽입
  • ✓ 어댑터 결합
  • ✓ 튜브팁 연결
  • ✓ 수밀 테스트

"조립 완료 → QC" 클릭.

⑤ QC 검수

사이드바 "✔️ QC". 4개 검사 항목 확인 후:

  • "통과 → 배송 등록" — 송장번호 자동 생성, 재고 차감 (TC-85, 노즐, 어댑터, 튜브팁)
  • "실패" — print_queued로 회귀 (재생산)

⑥ 재고 확인

사이드바 "📦 재고"에서 차감 결과 확인. 재고가 임계치 이하면 빨간 "재주문 필요" 뱃지가 뜹니다.

6치과 — 수령 및 환자 적용

다시 치과로 전환.

  1. 주문 목록에서 해당 주문 클릭 (상태: 배송 중)
  2. 모달에서 "수령 확인" 클릭 → delivered
  3. 다시 모달에서 "환자 적용 완료" 클릭 → applied (정산 대기)

7Point Shower — 정산 처리

Point Shower 관리자로 전환.

  1. 사이드바 "💰 정산" 클릭
  2. "정산 대기 목록"에서 방금 적용 완료된 주문 확인 — 분배 내역(기공소/그래피/Point Shower) 표시
  3. 오른쪽 "정산" 버튼 클릭 → settled

✓ 시연 마무리

  • 전체 대시보드에서 파이프라인 카운트 확인
  • Point Shower 매출 KPI에 ₩110,000 (수수료) 가산 확인
  • 주문 모달의 타임라인이 12단계 모두 채워진 것 확인

8샘플 파일 다운로드

시연용 STL 파일들 — 신규 주문에서 "📂 샘플 사용" 버튼이 자동으로 이 파일들을 가리킵니다. 별도로 다운로드해서 실제 STL 뷰어로 확인할 수도 있습니다.
