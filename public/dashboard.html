협업 모델 비교

모델 구조 이중우 수익 리스크 적합도
A. IP 라이센싱 Point Shower 설계/특허를 그래피에 라이센스, 그래피가 생산·판매 로열티 (매출의 3~8%) 낮음 특허 확보 시
B. 공동개발 (JV) 이중우(설계/임상) + 그래피(생산/유통) 공동 브랜드 이익 분배 (협의) 중간 ★ 추천
C. OEM 위탁생산 이중우가 Point Shower 브랜드 유지, 그래피에 생산만 위탁 직접 판매 마진 높음 (법인·자금 필요) 법인 설립 후
★ 추천: B. 공동개발 모델
현재 법인이 없는 상태에서 가장 현실적. 그래피 입장에서도 "임상의가 설계한 치과용 세정 디바이스"라는 스토리가 마케팅 자산이 됨. 초기에는 그래피 브랜드 산하 제품으로 시작하되, Point Shower 서브브랜드를 유지하는 형태가 양쪽 모두에게 유리.

비즈니스 로드맵 — 개인 치과의사 × 대형 소재 기업

지역 치과 원장 1인이 법인 없이, 리스크를 최소화하면서 대형 기업과 단계적으로 협업 관계를 구축하는 로드맵. 핵심 원칙: 그래피의 기존 인프라 위에 올라타되, IP와 임상 전문성으로 대체불가능한 포지션을 확보.
PHASE 0
NOW
✓ 현재 완료된 것
이미 확보한 자산 — 이것만으로도 제안의 기초가 됨
제품 설계 완료 3D 조립 뷰어 애니메이션 영상 SIDEX 부스 확보 강연 슬롯 확보
PHASE 1
4~5월
씨앗 심기 — IP 보호 + 임상 근거 확보
그래피에 제안하기 전에, 내 자산을 법적으로 보호하고 "이건 진짜 되는 제품"이라는 근거를 만드는 단계
특허/디자인 출원이중우 상표 등록 (Point Shower)이중우 임상 2~3케이스 촬영이중우 환자 피드백 수집이중우
왜 이게 먼저인가: IP 없이 대기업과 협의하면 아이디어만 빼앗길 수 있음. 특허 출원 접수증만 있어도 법적 보호력이 생김. 임상 근거는 "치과의사가 직접 쓰고 검증한 제품"이라는 그래피가 자체 생산으로는 만들 수 없는 스토리.
PHASE 2
5.29~31
데뷔 — SIDEX 강연 + 공식 제안
15분 강연으로 시장 반응을 증명하고, 그래피 의사결정권자에게 공식 제안서를 전달하는 단계
강연 (시장 수요 증명)이중우 1페이지 제안서 전달이중우 참관자 반응 수집공동 후속 미팅 일정 확보공동
강연의 숨은 목적: 청중 반응이 곧 시장 검증 데이터. "이 강연에서 N명이 관심을 보였고, M명이 가격 문의를 했다"는 사실이 그래피 경영진에게 가장 강력한 설득 재료. 3D 조립 영상은 "이 사람은 아이디어만 있는 게 아니라 실행력이 있다"는 것을 보여주는 장치.
PHASE 3
6~8월
파트너십 구축 — NDA → MOU → 공동개발 계약
법적 틀을 갖추고 역할 분담을 명확히. 법인 설립 없이 개인 자격으로 계약 가능한 구조로 설계
NDA 체결공동 MOU 체결공동 역할 분담 합의공동 소재 최적화 테스트그래피
개인 vs 법인: 이 단계에서 법인 설립이 꼭 필요하지 않음. "개인 발명자 ↔ 기업" 공동개발 계약은 법적으로 유효. 단, 수익 배분 조건을 명확히 해야 함. 추천 구조: 이중우 = 설계/임상 자문역 (로열티 또는 자문료), 그래피 = 생산/판매/인증 (투자+운영). 매출이 확인된 뒤에 법인 설립해도 늦지 않음.
PHASE 4
9~12월
제품화 — 인증 + 파일럿 생산
그래피 인프라로 인증 절차 진행 + 소량 생산 + 베타 테스트 치과 5~10곳 모집
KFDA 인증 진행그래피 소량 생산 (100세트)그래피 베타 치과 모집이중우 사용 데이터 수집공동
이중우의 핵심 역할: 베타 테스트 치과 네트워크. 동료 치과의사에게 "내가 직접 만들고 직접 쓰는 제품, 한번 써보라"고 할 수 있는 건 이중우만 가능. 그래피는 소재·장비 회사라 치과의사 대상 임상 설득력이 약함 → 여기서 이중우의 대체불가능성이 생김.
PHASE 5
2027~
스케일업 — 정식 출시 + 글로벌 확장
그래피의 글로벌 유통망(해외 80%+)을 타고 Point Shower을 세계 시장에 출시. 이 시점에서 법인 설립 검토
정식 양산그래피 FDA/CE 인증그래피 글로벌 유통그래피 KOL 마케팅이중우 법인 설립 검토이중우
법인 설립 시점: 매출이 실제로 발생한 뒤. 세금/수익 구조상 법인이 유리해지는 시점에 설립. 급하게 만들면 유지비만 나감. 그 전까지는 개인 사업자 또는 자문 계약으로 충분. 그래피 브랜드 산하 "Point Shower by Dr. Lee" 서브브랜드가 양쪽 모두에게 가장 가벼운 시작.
