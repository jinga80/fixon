## 0. 핵심 인사이트 정리 (사용자가 알려준 것)

| | 기존 (Aquapick / 워터픽) | 기존 (이갈이용 스플린트) | **FixOn** |
|---|---|---|---|
| 형태 | 핸드피스 + 노즐 | 단순 마우스피스 | 맞춤형 마우스피스 + 노즐 |
| 작동 | 사용자가 손으로 위치 조절 | 정적 (씹는 힘 분산만) | 장착 후 정밀 위치 자동 |
| 분사 매체 | 단순 물 (고압) | — | 물 / 세척액 / 약제 |
| 부위 적용 | 사용자 의지 / 균일도 낮음 | — | 환자별 필요 부위에 정확하게 / 균일하게 |
| 지속성 | 사용 중에만 | 정적 보호 | 일정 시간 지속 케어 |
| 의료기기성 | 일반 가전 | 보호 의료기기 | 표적 약제 도포 시 의료기기 |

→ **FixOn은 워터픽도 아니고 일반 스플린트도 아닌, 새로운 카테고리.**

## 1. 카테고리 명칭 (탐색 중)

### 한국어 후보
| 후보 | 장점 | 약점 |
|---|---|---|
| **맞춤형 구강 케어 트레이** | 직관적, '트레이'로 형태 명확화 | 의료적 무게 부족 |
| **표적 구강 케어 시스템** | 의료기기 신청서에 어울림 | 일반인 어려움 |
| **개인 맞춤 구강 도포기** | 약제 도포 강조 | "도포기" 어감 약함 |
| **웨어러블 구강 케어** | 트렌디 | 영어 의존 |
| **스마트 스플린트** | 익숙한 단어 활용 | 기존 스플린트 한계 연상 |
| **구강 케어 마우스피스** | 마우스피스 = 익숙한 단어 | 운동용 연상 |
| ⭐ **개인 맞춤 구강 케어 트레이** | 길지만 정확 | "트레이" 일반인 친숙도 ↑ 필요 |

### 영문 후보
| 후보 | 노트 |
|---|---|
| **Personal Oral Care Tray (POCT)** | Tray = 의치/스플린트 업계 표준 용어 |
| **Targeted Oral Therapy Tray** | 의료성 강조 |
| **CareFit Tray** | 브랜딩성 ↑ |
| **OraFit Platform** | 플랫폼화 (3-tier 모드 강조) |
| ⭐ **FixOn Care Tray** | 그대로 제품명 = 카테고리명 |

### 잠정 정의 (2026-04-28)
> **FixOn은 환자 개개인의 치아 본을 3D로 떠 만든 "맞춤형 구강 케어 트레이"입니다.**
> 입에 장착하면 미리 설계된 노즐이 잇몸과 치아의 필요한 부위로 정확하게 향하고, 카트리지의 세척액 또는 약제를 일정 시간 동안 균일하게 도포합니다.
> 손으로 잡고 움직이지 않아도, 사용자가 누워서 쉬는 동안 케어가 끝납니다.

→ 한 줄 카피: **"내 입 모양에 꼭 맞춘 케어. 손 대신 트레이가 합니다."**

## 2. 3-tier 모드 (사용 시나리오 구분)

| 모드 | 매체 | 위치 | 의료기기 등급 | 처방 필요 |
|---|---|---|---|---|
| **Daily** (일상) | 정수/세척액 | 가정 | 일반 공산품 | ✗ |
| **Wellness** (웰니스) | 잇몸 강화액·식물 추출물 | 가정/병원 | 건강 보조 | ✗ |
| **Medical** (의료) | 항염제·항균제·치료 약제 | 의사 처방 | Class 2 의료기기 | ✓ |

→ **하나의 트레이로 3가지 모드 호환** — 카트리지만 교체. 이게 핵심 차별점.

## 3. 브랜드 톤 (페르소나)

| 차원 | 위치 |
|---|---|
| 따뜻함 ↔ 차가움 | 따뜻함 70 / 차가움 30 (의료지만 무겁지 않게) |
| 기술 강조 ↔ 인간 강조 | 인간 60 / 기술 40 (정밀함은 자랑하지만 차가움 X) |
| 전문가용 ↔ 일반인용 | 일반인 70 / 전문가 30 (환자가 자기 입에 넣으니까) |
| 의료 ↔ 라이프스타일 | 의료 50 / 라이프스타일 50 (3-tier니까 둘 다) |

### 톤 키워드
- 정확한, 부드러운, 맞춤의, 안심되는, 새로운
- ✗ 차가운, 위협적인, 공포 마케팅, 기술 자랑

### 시각 톤
- 색조: 크림/베이지 베이스 + 따뜻한 오렌지 액센트
- 의료 신뢰성을 위한 다크 안전 정보 섹션 1개는 유지
- 일러스트: 미니멀, 둥근 모서리, 손그림 X (정밀 강조)

## 4. 포지셔닝 한 페이지

```
            [정밀 / 표적]
                │
                │
       ┌─ FixOn ─┐  ← 새로운 카테고리
       │         │
[자동] ┼─────────┼ [수동]
       │         │
   가글액      워터픽
       │
   일반 스플린트(정적)
                │
            [범용 / 비표적]
```

- **세로축**: 표적 정밀도 (필요 부위에만 작용 vs 전체)
- **가로축**: 자동화 정도 (장착하면 알아서 vs 손 필요)

→ FixOn은 우상단 **"자동 + 표적"** 사분면을 단독 점유.
